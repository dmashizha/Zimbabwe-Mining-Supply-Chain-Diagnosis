HOW TO USE THIS DOCUMENT IN MICROSOFT FORMS
--------------------------------------------
1. Go to forms.microsoft.com and click New Form
2. Set the form title and description from the FORM TITLE section below
3. For each question block, click + Add new question and choose the
   question type shown in brackets e.g. [CHOICE], [RATING], [TEXT]
4. Copy the question text exactly as written
5. For [CHOICE] questions, add each option on a separate line
6. For [RATING] questions, set scale to 1-5 and label the endpoints
7. For [TEXT] questions, set to Long answer
8. Section headers: use the Section button to group questions

NOTE ON SECTION G (RISK MATRIX):
Microsoft Forms does not support a grid/matrix natively.
Each risk row is entered as its own set of 3 rating questions
(Impact, Probability, Controls) plus one Choice question for Trend
and one Text question for Recommended Action.
A shortcut option is also provided at the end of this document.
